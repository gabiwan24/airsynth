# Air Synth
Synth und Drum-Machine, gespielt mit beiden Händen vor der Webcam.

**Live:** https://gabiwan24.github.io/airsynth/ (Chrome/Edge, Kamera erlauben)

- **Zeigefinger beider Hände** = Beat: Abstand → Tempo, Höhe → Grundton, Neigung → Groove, weiter rechts → Swing
- **Rechte Hand:** Daumen Drive · Mittelfinger Filter · Ringfinger Resonanz · kleiner Finger Ausklang
- **Linke Hand:** Daumen Hall · Mittelfinger Wobble · Ringfinger Breite · kleiner Finger Echo
- Leertaste = Beat starten / stoppen

Lokal: `start.bat` doppelklicken. Tests: `npm test`.
